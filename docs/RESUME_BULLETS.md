# JobPulse 简历项目话术（REQ-DEL-05）

> 3 条可直接粘贴进简历的 bullet，均含具体数值与统计口径。

## 话术 1（数据科学全流程）
> **JobPulse 招聘情报站**（Python/MySQL/XGBoost/ECharts）：从 GitHub 开源数据源采集 10,114 条真实招聘数据（10 城 × 5 类数据岗位），完成清洗建库（SQLAlchemy + MySQL，幂等 upsert + 快照表）、EDA 与技能图谱分析（jieba），输出 8 张可视化图表与 6 条可复现的行业洞察。

## 话术 2（建模能力）
> 构建 XGBoost 薪资预测模型：设计特征工程（城市/岗位类别/学历/经验/技能覆盖数 + 标题与 JD 文本特征，log 目标变换），按城市×类别分层 8:2 划分、固定种子、剔除实习岗防泄漏；测试集 **R² = 0.51**、MAE 8,733 元，优于线性回归基线（R² = 0.34），产出特征重要性 Top10 与模型评估报告。

## 话术 3（工程落地）
> 交付数据内嵌的单 HTML 交互看板（ECharts，双击即开、城市/类别/学历三维筛选联动）与一键链路脚本（check-env→建库→采集→分析→建模→看板→报告）；全流程 130+ 项 pytest 单测覆盖（薪资归一化 9 规则、幂等写入、反爬容错、增量快照），保障可复现与工程规范。
